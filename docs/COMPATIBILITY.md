# Compatibility and evidence

Runtime pins: Python >=3.11; asusrouter 1.21.3; aiohttp 3.14.5; keyring >=25,<26.
Authentication requires Linux desktop Secret Service. Helpers use native OpenSSH
or Python HTTPS and explicitly selected owner-provided configuration.

The package contains source capability inventories. Public audit metadata omits
household observations and marks prior selected live responses unverified.
The audit target is unspecified. Capability IDs, upstream source paths and line
references, declared contracts, recovery blocks and source versions are retained.
The audit hash therefore describes this public metadata, not a private audit.
It is separate from the unchanged runtime operation catalog and plan authority.

The expansion inventory is historical implementation metadata, not proof of live
support. No live response, phone outcome, speed improvement, filtering outcome,
restoration or compatibility on the reader's router is established by this export.
The test fixtures use synthetic values, reserved example domains and fictional
RFC1918 addresses when private-range validation itself is under test.

Private household automation, browser observers, pilot runbooks and the tests
that depend on those artifacts are excluded. Public offline test counts concern
only this exported suite. Package data, synthetic fixtures and permission/transport
regressions remain available without credentials or LAN access.

Some historical catalog source fields and the expansion report name reference
private design or review documents that are intentionally excluded from this
export. They are provenance labels, not bundled files. The operation catalog
remains byte-identical because its hash participates in plan bindings.
